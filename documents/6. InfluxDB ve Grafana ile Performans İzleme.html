Modül 6: InfluxDB ve Grafana ile Performans İzleme

Bu modülde JMeter testleri sırasında metrikleri canlı izlemek için InfluxDB ve Grafana entegrasyonunu uçtan uca kuracağız.

İçindekiler / Bölüm Haritası

  • Monitoring Nedir?
  • InfluxDB Mantığı ve JMeter Verisi
  • JMeter Backend Listener Konfigürasyonu
  • Grafana Dashboard Oluşturma
  • Uçtan Uca Akış ve Gerçek Zamanlı Yorum
  • Modül Özeti

1) Monitoring Nedir ve Neden Gerekli?

Monitoring, test sırasında metrikleri anlık izleyerek performans kırılmalarını canlı görmeyi sağlar. Test bitimini beklemeden riskli davranış yakalanır.

Neden Önemli?
Canlı izleme, test sırasında yanlış konfigürasyonu erken fark ettirir ve zaman kaybını azaltır.
Dikkat / Sık Yapılan Hata
Sadece test sonunda JTL dosyası okumak, olay anındaki sistem davranışını kaçırır.

2) InfluxDB Nedir? JMeter Verisi Nasıl Saklanır?

InfluxDB zaman serisi veritabanıdır. JMeter her isteğin metriklerini etiketli şekilde InfluxDB'ye yazar; Grafana bu verileri sorgular.

Doğrulama komutları
curl -I http://localhost:8086/ping
docker ps
Neden Önemli?
Zaman damgalı veri saklama, yük arttıkça metrik kırılımını doğru analiz etmeyi sağlar.
Dikkat / Sık Yapılan Hata
Yanlış database adı kullanmak nedeniyle JMeter verisi boş tabloya yazılabilir.

3) JMeter Backend Listener Kurulumu (Tıkla → Gör → Yap)

  1. Thread Group üzerinde sağ tık: Add → Listener → Backend Listener.
  2. Implementation alanında InfluxDB backend client seçin (plugin sürümüne göre ad değişebilir).
  3. Parametrelerde InfluxDB URL, database adı, application etiketi girin.
  4. Save ve test koşumu ile veri akışını başlatın.
Örnek parametreler
influxdbUrl=http://localhost:8086/write?db=jmeter
application=ERP-Perf-Test
measurement=jmeter
Neden Önemli?
Doğru backend listener ayarı yoksa Grafana paneli boş görünür.
Dikkat / Sık Yapılan Hata
URL içinde db parametresini yanlış yazmak veya firewall nedeniyle 8086 erişimini unutmamak gerekir.

4) Grafana Dashboard Oluşturma ve Metrik Görselleştirme

  1. Grafana'ya giriş: http://localhost:3000
  2. Sol menü: Connections → Data sources → Add data source.
  3. InfluxDB seçin, URL ve database alanlarını doldurun, Save & Test.
  4. Dashboards → New → Add visualization ile panel ekleyin.
  5. Sırasıyla Response Time, Throughput, Error Rate, Active Users panellerini oluşturun.
Neden Önemli?
Tek ekranda metrikleri yan yana görmek yorum hızını ve karar kalitesini artırır.
Dikkat / Sık Yapılan Hata
Farklı panel time range ayarları, metrikleri yanlış karşılaştırmaya neden olabilir.

5) JMeter + InfluxDB + Grafana Uçtan Uca Akış

  1. JMeter'da senaryoyu başlatın (tercihen non-GUI).
  2. Backend Listener metrikleri InfluxDB'ye akıtır.
  3. Grafana dashboard'ta anlık eğrileri izleyin.
  4. Kırılma anında kullanıcı yükü, response ve error davranışını birlikte yorumlayın.
Non-GUI örneği
jmeter -n -t erp_load_test.jmx -l sonuc.jtl
Neden Önemli?
Bu akış test sırasında kök neden adaylarını canlı tespit etmenizi sağlar.
Dikkat / Sık Yapılan Hata
GUI modda uzun yük koşturup JMeter kaynak tüketimi ile sonuçları bozmak.

Modül Özeti

Bu modülde test metriklerini canlı toplama ve görselleştirme altyapısını kurdunuz; artık testleri gözle görünür panellerle yönetebilirsiniz.

Bu Modülde Öğrendikleriniz

  • Monitoring yaklaşımının performans testiyle ilişkisi
  • InfluxDB'ye metrik yazma mantığı
  • Backend Listener ile JMeter entegrasyonu
  • Grafana data source ve dashboard oluşturma adımları
  • Uçtan uca gerçek zamanlı yorumlama disiplini
